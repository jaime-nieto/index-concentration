Both without dividends, return per year. The real index held the members of each day, including the companies that have since left it. Today's members are, by construction, the ones that did well enough to be in the index now, so the gap is the survivorship bias of the index-weights portfolio (plus the changes in the number of shares, which it ignores). Over one year the gap should be close to 0: it checks that the members and weights are right.
